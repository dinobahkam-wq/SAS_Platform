# Thmanyah Sans

ضع هنا جميع ملفات عائلة **Thmanyah Sans** التي زودتني بها، مع الحفاظ على أسماء الملفات الأصلية.

يفضل توفير ملفات WOFF2 للويب، ويمكن إضافة OTF أو TTF إذا كانت هي النسخ الأصلية المتاحة. ارفع كل الأوزان الموجودة ولا تفترض أوزانًا غير متوفرة.

بعد رفع الملفات سنفحص أسماء العائلة والأوزان وخصائص الخط، ثم نربطها في CSS عبر `@font-face`.
