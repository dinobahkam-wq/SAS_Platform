# SAS web fonts

مجلد الخطوط المعتمدة للموقع.

## العائلات
- `thmanyah-sans/`: عائلة Thmanyah Sans.
- `tajarib-taweel/`: عائلة Tajarib Taweel.

ارفع ملفات الخطوط الأصلية داخل مجلد العائلة المناسب. لا تغيّر أسماء الملفات ولا تخلط العائلات أو الأوزان. سنفحص الملفات ثم نضبط تحميل الخطوط وأوزانها في نظام التصميم.
