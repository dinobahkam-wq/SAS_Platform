# SAS brand assets

الأصول البصرية الرسمية لمنصة ساس.

- `logos/`: الشعار المعتمد بصيغته العربية «ساس» والعلامة اللاتينية «S A S».
- `icons/`: ملفات الأيقونات الرقمية المشتقة من العلامة المعتمدة، بعد اعتمادها.
- `../fonts/`: عائلات الخطوط المستخدمة في الموقع.

الهوية المعتمدة هنا هي العلامة الطباعية الهندسية «ساس» / «S A S» ذات بنية السين ذات الأسنان الثلاثة والعنصر الصاعد في الجهة اليمنى. لا تستخدم شعار البومة أو أي تصور سابق أو رمزًا بديلًا.
