# SAS digital icons

هذا المجلد مخصص للأيقونات الرقمية المشتقة من العلامة المعتمدة «ساس» / «S A S»، وليس لشعار مستقل أو رمز بديل.

## الملفات المطلوبة لاحقًا

- `favicon-32x32.png` — 32×32 px.
- `favicon-192x192.png` — 192×192 px.
- `apple-touch-icon.png` — 180×180 px.
- `icon-512x512.png` — 512×512 px.

يفضل أن تكون هذه الملفات PNG. لا تنشئ أيقونة جديدة أو تحذف عناصر من العلامة قبل مراجعة النسخة المعتمدة. إذا لم تكن هناك نسخة أيقونية مستقلة معتمدة، نؤجل هذه الملفات ونستخرجها لاحقًا من ملف المصدر بموافقة مدير المنصة.
