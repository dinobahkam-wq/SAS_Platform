# SAS brand icons

ضع هنا الأيقونات المشتقة من الشعار والمعتمدة للاستخدام الرقمي، مثل:
- favicon بصيغة ICO أو PNG.
- أيقونة مربعة للتطبيقات والمنصات الاجتماعية.
- أيقونات الشعار المصغرة بمقاسات متعددة.

لا تضع هنا ملفات الخطوط أو النسخ الرئيسية للشعار؛ مكانها `public/fonts/` و`public/brand/logos/` على التوالي.
