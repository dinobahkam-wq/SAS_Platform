# SAS brand logos

ضع هنا ملفات الشعار الرسمي المعتمد لمنصة ساس، بما فيها شعار البومة والاسم العربي.

## الملفات المطلوبة
- النسخة الأفقية الأساسية: SVG مفضل، أو PNG بخلفية شفافة.
- الرمز المنفرد (البومة) لاستخدامه في الأيقونة والمساحات الصغيرة.
- نسخة أحادية اللون عند توفرها.
- نسخ فاتحة/داكنة عند توفرها.

يمكن الإبقاء على أسماء الملفات الأصلية عند الرفع. لا تعِد رسم الشعار ولا تستبدله بحرف S أو برمز مؤقت.

يفضل أن يكون ملف SVG أصليًا ونظيفًا. إذا لم يتوفر، ارفع PNG شفافًا بأعلى دقة متاحة. لا تستخدم JPG للشعارات ذات الخلفية الشفافة.
