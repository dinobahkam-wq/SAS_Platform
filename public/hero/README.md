# الصور الرئيسية لمنصة ساس

هذه مساحة صور السلوغن في الصفحة الرئيسية. ضع الصور الأربع المعتمدة هنا بصيغة **WebP** وبهذه الأسماء بالضبط:

- `yemen-identity.webp`: الهوية اليمنية
- `yemen-history.webp`: التاريخ والعمران اليمني
- `yemen-war.webp`: الحرب وآثارها
- `yemen-peace.webp`: السلام والتعافي

المقاس المقترح: أفقي 1920 × 1080 أو أعرض، وضغط مناسب للويب (يفضل أقل من 500 كيلوبايت للصورة إن أمكن). تظهر الصور مع معالجة رمادية ناعمة وتلاشي لوني، ويستبعد العارض أي ملف لم يُرفع بعد دون إظهار صورة مكسورة.

العارض ينتقل تلقائيًا كل 7.8 ثوانٍ، ويتيح الانتقال اليدوي عبر مؤشرات أسفل الصورة. يحترم إعداد تقليل الحركة.

**مهم:** لا تنسخ صورًا أو بيانات سياسية حساسة إلى هذا المجلد دون حقوق نشر وتحقق من المصدر. لا تُستخدم صور المحتوى كدليل على وقائع في الموقع، بل كخلفية تعبيرية فقط.
