# Package 02 — جرد المحتوى السياسي القديم وتجهيز ترحيل آمن

**التاريخ:** 11 نوفمبر 2026  
**الحالة:** جرد أولي فعلي، بلا استيراد، بلا تعديل قاعدة بيانات، بلا نشر  
**ملف آلي:** [العينة المنظمة](inventory/legacy-2026-09-11_2026-11-11.sample.json)

## النتيجة المحققة

- تم التحقق من **14 صفحة مقالة فردية** من مصدر ساس العام خلال الفترة 13 سبتمبر إلى 8 نوفمبر 2026، وتسجيل الرابط والتاريخ والعنوان والتصنيف المقترح.
- **9 مرشحة مباشرة** ضمن الشأن السياسي، **3 للمراجعة التحريرية** بسبب ارتباطها بالسياسات العامة بدرجات متفاوتة، **1 مؤجلة**، و**1 مستبعدة** من واجهة ساس السياسية (خبر رياضي).
- العينة **ليست تعدادًا شاملًا** لمحتوى آخر شهرين، وليست نسخة كاملة من المتن أو الوسائط أو المؤلفين.
- لا توجد في العينة المحققة مادة تأكدت صفتها كدراسة بحثية أو تحليل رأي؛ **لا تعِد تسمية خبر عادي دراسةً أو تحليلًا** لملء القسم.
- لم تُستورد أي مادة إلى Supabase ولم تُنسخ وسائط.

## قاعدة التحرير: الهوية السياسية أولاً

| المسار | معيار الاختيار | التمثيل البصري |
|---|---|---|
| الأخبار والشؤون الجارية | قرار مؤسسي، عملية سياسية، أمن ودفاع، دبلوماسية، علاقات خارجية، سياسة عامة ذات دلالة | خبر منضبط + وقت + مصدر + جهة القرار |
| التحليل والرأي | نص أصلي تحليلي يحتوي تفسيرًا وحجة وبصمة مؤلف، لا بيانًا خبريًا | عنوان Serif + مؤلف + قراءة زمنية + إحالات |
| الدراسات والأبحاث | ورقة بحث أو سياسات موثقة بمنهجية وملخص ومراجع | غلاف بحثي + مؤلف + بيانات إصدار + مصادر |
| البرامج والوسائط | حلقة صوتية/مرئية سياسية أو تفسيرية مسندة | بطاقة برنامج، مقدم، مدة، رابط ملف |

**لا يتحول كل ما نشرته ساس سابقًا تلقائيًا إلى محتوى للنسخة الجديدة.** التقارير الرياضية والمنوعات الخدمية العابرة ليست محور الواجهة؛ تقيّم الأخبار التنموية وفق صلتها بالحوكمة والموارد والمؤسسات.

## تشخيص المصدر

- الاتصال بمكوّن WordPress يسرد موقع `sas-media.net` المرتبط بـJetpack، لكن مسار استرجاع `posts_list` أعاد HTTP 404 مع متن غير JSON، حتى مع رقم الموقع.
- الموقع العام يقدّم المقالات في مسارات `/post/{id}`. **هذه قرينة تحتاج فحصًا على نظام النشر الفعلي** ولا تثبت أن REST الخاص بووردبريس يمثل مصدر النصوص الحقيقية.
- الحل التالي هو جرد معماري غير تدميري: استعلام DNS/استجابة headers، كشف `robots.txt` و`sitemap.xml` وأنماط مصدر الصفحات، اختبار REST المتاح، والتصدير الرسمي من لوحة الإدارة إن كان متاحًا.
- يُفضّل التصدير الأولي المنظم والمصرّح به من CMS. يُستخدم جمع الصفحات العامة كبديل جزئي بعد التأكد من سياسة الوصول والحقوق، ولا يسترجع المسودات أو بيانات المؤلفين الكاملة.

## بروتوكول الترحيل المقترح

1. أنشئ فهرسًا شاملاً للفترة (شهران) بتسجيل URL والمعرف والتاريخ والمنشئ والقسم والصور الأصلية.
2. نفّذ تجريد HTML المنظم إلى `body.blocks` مع الحفاظ على الفقرات والقوائم والروابط والاقتباسات. تحقق من عدم حقن HTML ضار؛ حافظ على النص الأصلي.
3. احفظ مرجع المقال القديم في manifest دائم مستقل قبل أي تغيير لقاعدة البيانات؛ لا تقحم حقل `legacy_id` غير موجود في مخطط Supabase الحالي دون Migration مرخصة.
4. افحص المصادر والإسناد: البيان السياسي يُنسب إلى الجهة الرسمية، و«نقلًا عن» لا يتحول إلى تحقق مستقل.
5. لا تنشر تلقائيًا. ابدأ بعينة 8–12 مادة كمسودات في بيئة منفصلة أو بتفويض صريح لمشروع الهدف، ثم راجع نسخها وروابطها.
6. استورد الوسائط المرخصة فقط؛ إن كانت الحقوق غير واضحة، اترك المادة دون غلاف مؤقتًا واستكمل المعالجة.
7. اجعل الاستيراد **idempotent**: المفتاح `source_system + legacy_id`، وسجل import job ومحصلة النجاح والفشل؛ لا تكرر نفس المقال.
8. حافظ على التاريخ المنشور الأصلي مع المنطقة الزمنية بعد التحقق، وافحص الموجهات 301 وcanonical وSEO بعد اعتماد النطاق الجديد.

## مراجعة الملفات المرفقة من المستخدم — امتداد

**المصدر الأول:** لقطة PDF من أربع صفحات لواجهة `imtedad.net`، بتاريخ 11 نوفمبر 2026.

- ص 1: غلاف صورة رمادية ونص أسود كبير، ثم شريط «الأحدث» وكروت «مختارات» بتراتب تحريرية.
- ص 2: غلافات صور كاملة في شريط «كاليدوسكوب» والعنوان فوق الصورة، يليها عرض «فضاء».
- ص 3: بورتريهات لكتاب وشخصيات، ومراجعات ذات مساحات واسعة.
- ص 4: تذييل تنظيمي وبنية روابط مؤسسية؛ لا داعي لنسخ تنظيم أقسام امتداد كما هو.

**المصدر الثاني:** خمس صور JPEG ترويجية في ملف ZIP: بطاقة العنوان «جيل يتلقى اليمن من شاشة!»، صورة الكاتب، «شاشة صغيرة»، «الاحتكاك المباشر»، «تعقيدات المجتمع». استخدمت خلفية خضراء حيّة وأبيض/أسود فوتوغرافيًا وشخصيات وعناصر هاتف/باب/مكبر صوت، مع قوالب طباعية ذات أثر بصري قوي.

**الاستخدام المسموح تصميميًا:** استلهام مبادئ التباين وبناء الرموز والاستعارة البصرية لتصميمات جديدة أصيلة لمنصة ساس؛ **لا تنسخ التصاميم أو الصور أو الشعارات أو النصوص ولا ترفعها لمستودع ساس** من دون حقوق صريحة.

### ترجمة ذلك إلى هوية سياسية ساس

- **غلاف ملف سياسي:** خريطة مبسطة أو وثيقة أو silhouette لعمارة محلية + سؤال أو فرضية سياسية محددة، لا غلاف تراثي سياحي عام.
- **سلسلة «تحت المجهر»:** مقتطف من قرار/بيان أو خط زمني، مرتبط بمصدر رسمي ورابط تحقق.
- **الخبر:** صورة حقيقية للحدث مع تاريخها ومصدرها، وليس صورة معمارية ترمز زيفًا لحدث أمني.
- **الدراسة:** واجهة شبيهة بوثيقة بحثية، تراتبية قوية بالخطوط المعتمدة، مؤلف وإصدار وملخص تنفيذي.
- **المؤثرات:** انتقال 120–220ms للبطاقة أو القائمة، ويحترم `prefers-reduced-motion`، بلا parallax ثقيل أو تحريك تلقائي للعناوين.

## الخطوة التالية

تحديد مصدر تصدير المحتوى الفعلي وقراءة 8–12 مادة كاملة؛ ثم مراجعة محوّل HTML → blocks والاستيراد التجريبي على بيئة آمنة قبل أي نشر. إذا تعذر API القديم، احصل على نسخة XML/JSON/CSV أو export رسمي من إدارة موقع ساس أو من مزوّد استضافته.

**ملاحظة:** هذا الملف جزء من فرع توثيق، وليس إعلانًا بدمج أي تعديل بالواجهة في `main`.
