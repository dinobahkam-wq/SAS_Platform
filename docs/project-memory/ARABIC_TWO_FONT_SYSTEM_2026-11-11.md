# Arabic Two-Family Typography v1 — سجل التنفيذ

**التاريخ:** 11 نوفمبر 2026  
**الفرع:** `feat/two-font-editorial-system-v1`  
**الأساس:** رأس `feat/editorial-surface-polish-v1` بعد PR #15

## القرار

اعتماد عائلتين فقط في الواجهة العربية:
- Tajarib Taweel للعناوين التحريرية.
- Thmanyah Sans للمتن والواجهة والبيانات.

أُلغي استخدام Thmanyah Serif Display من CSS الفعّال؛ بقيت ملفات الخط القديمة في المستودع دون استدعاء أو حذف، إلى حين مراجعة الترخيص والحاجة التاريخية إليها.

## ما نُفذ

1. إزالة تعريفات `@font-face` الخمسة الخاصة بـThmanyah Serif Display من `src/app/globals.css`.
2. تحويل جميع الإحالات الطباعية النشطة إلى Tajarib Taweel، بما فيها متغيرات عنوان المقال والعناوين الداخلية ونماذج المنتجات.
3. توحيد المتغيرات `--font-editorial-title` و`--font-editorial-heading` على Tajarib Taweel.
4. رفع وزن العناوين الداخلية الدلالية إلى 700؛ مع الإبقاء على 500 للعناوين الثانوية حيث يلائم التراتبية.
5. تحديث وثيقة اعتماد النظام الطباعي لتسجيل القرار الجديد بوصفه تعديلًا يحل محل نظام العرض المزدوج السابق.
6. تحديث README وإضافة `docs/editorial-arabic-style-v1.md` لسياسة التشكيل والتحرير.

## الأوزان المتاحة فعليًا في ملفات CSS

- Tajarib Taweel: 300، 400، 500، 700، 900.
- Thmanyah Sans: 300، 400، 500، 700، 900.

لم تُضف أوزان 600 أو 800 غير الموجودة كملفات مستقلة. يجب عدم افتراض توافرها في المتصفح أو استدعائها بوصفها ملفات حقيقية.

## سياسة التشكيل

- الأصل عدم تشكيل النصوص التحريرية.
- إضافة الحركات فقط لإزالة التباس لغوي مؤثر أو لصحة نقل اسم/اقتباس/نص.
- لا تشكيل آلي شامل، ولا تعديل جماعي لبيانات Supabase.
- السياسة التحريرية لا تدّعي أن التشكيل يجعل النص بشريًا؛ الأصالة تأتي من التحرير والإسناد والدقة.

## نتائج مراجعة المصدر

- لا توجد أي إحالة نصية إلى `Thmanyah Serif Display` داخل `src/app/globals.css` بعد التعديل.
- لا توجد تعريفات `@font-face` للعائلة المحذوفة من CSS.
- العائلات النشطة في CSS هي Tajarib Taweel وThmanyah Sans.
- تم تحديث الوثائق المرجعية لتوضح أن القرار الجديد supersedes نظام B السابق ذي الخطين العرضيين.

## ما لم يُختبر بعد

لم يُشغّل `npm run typecheck` أو `npm run build` أو مراجعة بصرية في متصفح Windows بعد هذه التعديلات. يجب اختبار:
- الصفحة الرئيسية: عنوان البطل وعناوين الأقسام.
- /news: البطاقات وشريط الأخبار.
- /content/[slug]: عنوان المادة والعناوين الداخلية والمتن.
- /brand-preview/products-b: عينات المنتجات بعد إزالة Serif Display.
- عرض الهاتف 360 و390 بكسل، وسطح المكتب.
- عدم ظهور وزن مصطنع أو fallback serif في العناوين.

لا تغييرات على Supabase أو المحتوى المنشور أو المصادقة أو النشر الإنتاجي. لا دمج إلى main ضمن هذه الحزمة.
