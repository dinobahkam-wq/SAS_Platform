# Package 02 — مراجعة ملف الترحيل الحقيقي لآخر شهر

**تاريخ المراجعة:** 11 نوفمبر 2026  
**المصدر:** `sas-last-month.json` رفعه المشغّل في المحادثة؛ **لا تُرفع النسخة الكاملة أو المتون إلى GitHub العام**.  
**الفترة:** 11 أكتوبر–11 نوفمبر 2026.

## نتائج العينة الكاملة

- 38 مادة في الملف، مع نص HTML كامل وعنوان ورابط معرف وتواريخ ومرجع الوسائط.
- 20 مادة مقترحة لمسودات أخبار سياسية، و12 للمراجعة التحريرية (حكم محلي/تنمية/سياسات عامة)، و6 مستبعدة من نطاق المنصة السياسي الحالي (مثل النتائج الرياضية والأنشطة الخدمية).
- جرى محليًا تجهيز معاينة JSON لـ20 مسودة، تتضمن 94 فقرة نصية محفوظة من المصدر دون صور، بحالة `draft` و`published_at: null` ومرجع المصدر خارج حقول CMS. **لم تُكتب هذه المسودات إلى Supabase**.
- جميع الحقول `published_local` و`published_gmt` متطابقة داخل العينة؛ لا تعتمد توقيت UTC الصحيح دون فحص إعداد المنطقة الزمنية بالموقع.
- لا يوجد ضمن المحتوى المحقق تحليل رأي أصيل أو دراسة بحثية؛ تُخصص هذه المواد لقسم الأخبار فقط.
- تتضمن بعض المواد السياسية ادعاءات عسكرية وتصريحات سياسية صادرة ضمن سياق أرشيفي. لا تنشرها بوصفها تحققًا مستقلاً؛ انسب البيان للمتحدث وابحث عن البيان الرسمي والمصدر الأول قبل نشره باسم ساس الجديدة.

## ما الذي يمنع الكتابة المباشرة إلى قاعدة الإنتاج؟

1. **قرار الفرز أولي:** لا تنشر أو تعامل هذه العينة على أنها معتمدة تحريريًا. 
2. **المصدر والأوقات:** الروابط الأصلية محفوظة في ملف المعاينة لكن مخطط `content_items` الحالي لا يتضمن حقولًا مستقلة للـ legacy ID والـ original time، مما يستلزم آلية ربط موثقة عبر `content_sources` أو manifest آمن.
3. **الصور:** يرفعها المستخدم بنفسه؛ لا تستورد صور WordPress المضمنة.
4. **التاريخ:** احتفظ بالتاريخ الأصلي الوارد في WordPress وبحالة `draft` عند الاستيراد؛ لا تجعل تاريخ النشر الحالي يحل محل النشر التاريخي.
5. **سياسة النشر:** تحقق من بيانات المصادر الرسمية قبل اعتماد أخبار المواجهات والقرارات المقتبسة.

**توصية التنفيذ:** مراجعة تصنيف 20/12/6، ثم إعداد مستورد `draft-only` محمي من التكرار يحفظ روابط WordPress والمصدر التاريخي، ثم كتابة دفعة مسودات وإجراء استعلام تحقق بعد موافقة تحريرية؛ تبقى الصور عملًا يدويًا.
