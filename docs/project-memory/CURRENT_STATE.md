## تحقق إضافي من API ومصدر المحتوى — 11 نوفمبر 2026

- **مخرجات المشغل المحلية:** 12 طلب فحص؛ `/wp-json/` و`/wp-json/wp/v2/posts?per_page=1` يعيدان HTTP 200 `application/json` على `sas-media.net` و`www.sas-media.net`؛ النطاق العاري يحوّل الصفحة العامة إلى `www`.
