## 11 نوفمبر 2026 — نشر دفعة صور الأخبار الفعلية

- طلب المشغّل نشر الأخبار التي رُفعت صورها وتجربة الموقع، مع تأجيل باقي الصور والنشر لاحقًا بأخبار جديدة.
- **التحقق من Storage:** وُجدت **ست صور WebP** ضمن `sas-public-media/legacy/`، للمعرّفات `5712,5809,5816,5826,5842,5856`. أشار المشغّل إلى سبع صور، لكن الاستعلام على الحاوية لم يُظهر السابعة؛ لا نفترض رفعها.
- **النشر إلى Supabase (مُنجز ومتحقق):** نُشرت ست مواد `status=published` في `public.content_items`، وربطت جميعها بالصور `media_assets` والمصادر الأصلية `content_sources` و`content_source_links`، وأُبقيت تواريخ النشر التاريخية وفق تفسير تاريخ WordPress المحلي بتوقيت عدن `Asia/Aden` مع تدوين عدم تحقق المنطقة الزمنية الأصلية. لم تنشر مواد أخرى.
- **التحقق بعد الكتابة:** أعاد استعلام مستقل ستة سجلات وكل منها `published` وله `cover_asset_id` و`object_path` و`source_url` ونصوص `body.blocks`.
- **فهرس المواد المنشورة:** `5856` (زيارة مأرب)، `5842` (الإعلام والتماسك الوطني)، `5826` (ميناء الشحر والعقار)، `5816` (التعديل الوزاري)، `5809` (العلاقات الفرنسية)، `5712` (تصريح التحالف حول مطار الملك خالد).
- **قيد تحريري:** المواد من أرشيف الموقع القديم، وبعضها ينقل ادعاءات أو تصريحات سياسية/عسكرية لم تتحقق منها ساس الجديدة استقلاليًا؛ نُسبت إلى مصدرها، ويُستحسن إجراء مراجعة مصادر رسمية قبل إبرازها في منتجات تحليلية لاحقة.
- **واجهة الموقع:** كود `src/app/page.tsx` و`src/app/news/page.tsx` يقرأ المواد المنشورة ديناميكيًا عبر `getPublishedContent` ويضيف الصورة عبر `media_assets`. لم أتمكن من اختبار `localhost:3000` في متصفح المستخدم مباشرة؛ تبويب localhost في Browser connector أعاد error page. يحتاج المشغّل تشغيل `npm run dev` ثم معاينة الرئيسية و`/news` وتقديم لقطة.
