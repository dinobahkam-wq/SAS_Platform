### تشغيل المحتوى الفعلي

- أفاد المستخدم بنجاح نشر ستة أخبار في تجربة سابقة وربط صورها من مكتبة الوسائط. هذه إفادة تشغيلية من المستخدم؛ لم تُجرَ مطابقة جديدة مع سجلات Supabase في هذا التحديث.
- جرد WordPress المحلي بلغ 76 مادة في ملف خاص خارج المستودع، مع أربعة أرقام تاريخية متطابقة مبدئيًا (5816 و5762 و5788 و5599). لا يعني الجرد أن المحتوى استورد أو نُشر في قاعدة ساس.
- مسار الاستيراد المفضل: موصل WordPress لسحب النصوص، مع رفع المستخدم الصور إلى Supabase Storage وربطها يدويًا بكل مادة.
