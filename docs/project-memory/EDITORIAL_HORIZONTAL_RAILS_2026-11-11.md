# حزمة العرض التحريري الأفقي — 11 نوفمبر 2026

**الحالة:** منفذة على GitHub في فرع مستقل؛ يحتاج الاختبارات المحلية قبل الدمج.

## قرار المنتج

منصة ساس منتج سياسي ومعرفي سياسي، وليس مجلة عامة. نستخدم تصميم الصحيفة المرجعي في كثافة البطاقات ووضوح تراتبية المواد **دون** استعارة تصنيفاته الثقافية.

## التغييرات

- الصفحة الرئيسية: استبدال البطل الإخباري الضخم بمقدمة مؤسسية مدمجة، وصفوف أفقية للأخبار حسب تنسيقها (تقارير إخبارية، أخبار موجزة، بيانات وقرارات رسمية)، ثم صفوف خاصة بالتحليل، والأبحاث، والبرامج عندما يتوافر محتواها.
- صفحات الأقسام: يعرض كل قسم صفوفًا أفقية بحسب `format` الموجود بالفعل في `content_items`. لا تخلط الأخبار بالدراسات.
- `EditorialRail`: بطاقات مضغوطة بنسبة صورة `16:9` وتفاصيل النوع والتاريخ والعنوان والمقتطف والمصدر؛ التمرير باللمس/لوحة اللمس أو أزرار الأسهم، مع إمكانية الوصول عبر لوحة المفاتيح.
- النقر على البطاقة: نافذة `dialog` أصيلة تدعم Escape والتركيز، تعرض الصورة الأكبر والنص الكامل وتوقيت عدن وروابط مصادر الخبر ورابط المادة المستقل. رابط المادة يبقى للحفظ والمشاركة والفهرسة.
- تحميل المصدر على هيئة استعلامات دفعة واحدة بدل استعلام لكل خبر.
- احترام `prefers-reduced-motion`.

## أحجام الصور المعتمدة للعمل

| الاستخدام | نسبة الأبعاد | دقة الرفع المفضلة |
| --- | --- | --- |
| صورة البطاقة الإخبارية | 16:9 | 1200 × 675 |
| الصورة الرئيسية عالية الجودة | 16:9 | 1600 × 900 |
| التغطيات المصورة | 3:2 | 1200 × 800 |
| غلاف دراسة أو ورقة | 3:4 | 1200 × 1600 |
| صورة شخصية | 4:5 | 800 × 1000 |

اختر WebP غالبًا، واستهدف نحو 100–250KB لبطاقة الخبر إن لم تتدهور التفاصيل. الملفات تُضغط قبل الرفع، دون إعادة تسمية JPEG كـWebP شكليًا. الحاوية الحالية تقبل WebP/JPEG/PNG/AVIF حتى 10MB، وجدول الوسائط يقيد البعد الواحد حتى 2560px.

## اختبارات القبول المحلية

1. `npm run typecheck`
2. `npm run build`
3. فحص `/` و`/news` على شاشة واسعة وشاشة هاتف.
4. تظهر 6 مواد أخبار فعلية، في صفوف: 4 تقارير و2 أخبار موجزة، ولا توجد صفوف فارغة للبيانات الرسمية.
5. الأزرار والتمرير باللمس يعملان دون إزاحة عرض الصفحة خارج نافذة المتصفح.
6. النقر على كل بطاقة يفتح نافذة بالنص الكامل، وتغلق بزر × أو Escape.
7. رابط المصدر ورابط صفحة المادة صحيحان؛ أسماء الأشهر عربية والأرقام لاتينية.
8. تركيز لوحة المفاتيح ظاهر والحركة تتوقف عند تقليل الحركة.

## حدود الحزمة

- لا تغيير Supabase أو مصادر الأخبار أو صلاحيات النشر أو الصور.
- لا تغيير الخطوط System B والشعار.
- لم تُختبر هذه النسخة على Windows بعد؛ PR مسودة وليس دمجًا إلى `main`.
- الصورة المرجعية الخارجية **مصدر إلهام لترتيب الصفوف**، لا أصل يجوز نسخ شكله أو خطه أو صوره.
