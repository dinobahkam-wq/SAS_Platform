## الإصلاحات المنفذة

### بطاقة الخبر

- اعتماد زوايا `14px` وظلال خفيفة وحالة تحويم منضبطة دون إعادة تصميم الألوان والخطوط المعتمدة.
- إبقاء نسبة الصورة `16:9` مع إدماج وسم نوع المادة قرب أسفل الصورة، وتظليل محدود لتوضيح الانتقال إلى النص.
- إخراج `نوع المادة` من سطر التاريخ، وتحويل سطر المعلومات إلى تاريخ + قسم صغير، ثم العنوان والمقتطف.
- جعل تذييل البطاقة مكوّنًا ذا وظيفتين: اسم الناشر/الأرشيف، وإشارة «قراءة المادة» مستقلة بصريًا.
- الحفاظ على إمكانية الوصول إلى النص الكامل عبر نافذة القراءة ورابط صفحة الخبر المستقلة.

### نافذة القراءة

- نقل عنوان الخبر والبيانات التحريرية والتوقيت أعلى الصورة؛ تجنب ظهور صورة ضخمة قبل معرفة الموضوع.
- تغليف الصورة ضمن `figure` مع تعليق `figcaption` إذا توافر، والحفاظ على `object-fit: contain` حتى لا تُقص صور المصدر أو وجوه الأشخاص.
- تقليص مناطق التشتت البصري، وضع خط قراءة أهدأ مع عرض متن محدود.
- تنعيم زر الإغلاق والحدود والخلفية والظلال، وتوفير روابط المصادر ورابط المادة الكاملة.
- في الهاتف: نافذة قراءة قريبة من bottom sheet بعرض الشاشة وارتفاع أقصى `94dvh`، تمرير داخل النافذة ودعم Escape عبر `dialog` الأصلي.

### الجوال

- فصل شريط رأس الصفحة إلى مستويين تحت `760px`: شعار + الدخول، ثم صف مستقل لأقسام الموقع الأربعة.
- إزالة ضغط الخطوط والأزرار في شريط التنقل، مع توزيع متساوٍ وروابط قابلة للالتفاف.
- الحفاظ على صفوف الأخبار الأفقية والبطاقة المرئية وجزء من البطاقة التالية، مع ضبط أحجام النص والمسافات.

### توحيد الهوية

- متغيرات للأركان والظلال والأسطح الهادئة دون تبديل الأخضر المؤسسي أو System B.
- تحويل حقوق النشر في التذييل إلى عبارة عربية.
- عدم تعديل البيانات أو صور Storage أو الأسعار أو إعدادات Supabase.

## القيود وما يحتاج اختبارًا

- التعديل مرفوع إلى فرع GitHub؛ **لم يُختبر `npm run typecheck` أو `npm run build` أو الواجهة الحية على Windows بعد التعديل**.
- الصورة المرفوعة لخبر مأرب تظهر في نافذة القراءة وبها تكوين رأسي وعلامة `Ps` ظاهرة ضمن الصورة الأصلية وفق لقطة المستخدم؛ CSS لا يستطيع إزالة علامة مضمنة داخل الصورة، ويحتاج المستخدم إلى استبدال الصورة المصدر المصرّح بها ونسخة WebP صحيحة إذا كانت غير مقصودة.
- اختبر حركتي RTL والانتقال بين البطاقات، فتح النافذة وإغلاقها بزر × وEscape، تمرير الصفحة عند فتح النافذة، قراءة المصدر، واستجابة 360 / 390 / 768 / 1440 بكسل.
- في حال ظهور خلل بالواجهة يجب إصلاحه على الفرع قبل الدمج في `main`. لا تدمج سلسلة الطلبات تلقائيًا.

## معايير القبول

1. البطاقة متوازنة بصريًا مع عدم قص النص خارج الحواف.
2. الصورة والعنوان والمقتطف يظهرون كوحدة واحدة في بطاقة ناعمة الحواف.
3. النافذة تعطي الأولوية للعنوان قبل الصورة، ولا تترك هوامش خالية كبيرة غير ضرورية.
4. لا ينضغط شعار ساس والأقسام الأربعة في سطر الهاتف.
5. في الهاتف، النافذة قابلة للقراءة والإغلاق والتمرير دون انزياح أفقي.
6. البيانات المنشورة ومراجع المصادر لم تتغير.
