# نقل محرك استوديو الصور الإخبارية إلى SAS Platform

- المصدر: `dinobahkam-wq/SAS`، الفرع `feature/news-card-studio-v1`.
- الوجهة: `dinobahkam-wq/SAS_Platform`، المسار `src/app/admin/news-studio/page.tsx`.
- فرع النقل: `feat/news-studio-migration-v1`.
- المسار التشغيلي الجديد: `/admin/news-studio`، محمي تلقائيًا بواسطة `src/app/admin/layout.tsx` و`requireAdmin()`.

## ما تم نقله
- محرك تخطيط ورسم Canvas ومعاينة مباشرة وتصدير PNG.
- قوالب الخبر والعاجل والبيان الرسمي والاقتباس.
- المقاسات الجاهزة والمخصصة، لوحات الألوان، الصور وأوضاع القص، الموجز والمصدر وحقوق الصورة.
- تخطيط النص المتكيف، تقسيم البيانات متعددة الصفحات، وإعدادات القوالب المحلية.

## توطين الهوية
- عناوين البطاقات تستخدم عائلة `Tajarib Taweel`.
- نصوص الواجهة والبيانات تستخدم `Thmanyah Sans`.
- الشعار يُحمّل من `/brand/logos/sas-logo-for%20white%20background.png` من المستودع الجديد.
- لا توجد إحالة إلى شعار أو خطوط أو API من المشروع القديم.

## فصل البيانات
- أزيلت استدعاءات RPC القديمة `sas_public_directory` و`sas_public_related` لأنها تخص مخطط قاعدة البيانات القديمة.
- لا يقرأ هذا الإصدار بيانات أو يكتبها في Supabase؛ الإدخال والتصدير محليان، ولا ينشر تلقائيًا.
- ربط الاستوديو بالمادة التحريرية ومكتبة الوسائط الحالية مرحلة لاحقة منفصلة.

## التحقق المطلوب
1. `npm run typecheck`
2. `npm run build`
3. افتح `/admin/news-studio` بعد تسجيل الدخول.
4. اختبر خبرًا بصورة ومن دون صورة، والعاجل، والبيان متعدد الصفحات، والاقتباس.
5. اختبر PNG للمقاسات 1080×1350 و1080×1080 و1200×675.
6. تحقق من ظهور الشعار والخطوط العربية في المعاينة والملفات المصدرة.
