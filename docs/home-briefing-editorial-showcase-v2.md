# واجهة الإحاطة في الرئيسية — الحزمة الثانية

**التاريخ:** 18 نوفمبر 2026  
**الفرع:** `feat/home-briefing-editorial-showcase-v2` (غير مدمج في `main`).

## الهدف

استبدال بطاقتي التعريف بالمنتج والعدد الأخير ببطاقة تحريرية واحدة كثيفة ومنظمة. يكون العدد المنشور نفسه هو مركز تجربة القراءة، مع أيقونات خطية رسمية صغيرة فقط، من دون إضافة صور أو زخارف أو اعتماديات خارجية.

## التنفيذ

- `src/components/home-briefing-showcase.tsx`: مكون Server Component يعرض بيانات أحدث إصدار منشور من الأرشيف، وثلاثة مقتطفات من الملخص التنفيذي، وعدادات التطورات/الخلاصات، ورابط العدد.
- `src/components/home-briefing-showcase.css`: تقسيم ثنائي على الشاشات الواسعة، وعمود واحد متجاوب للهاتف، مع دعم الألوان المتغيرة و`prefers-reduced-motion` وتركيز لوحة المفاتيح.
- `src/app/page.tsx`: جلب آخر 3 أعداد من `getPublicBriefingArchive` وتفاصيل أحدث عدد عبر `getPublicBriefing`، مع إبقاء الأرشيف قابلاً للعرض إذا تعطلت تفاصيل العدد.
- الإصدارات السابقة تُعرض بروابط حقيقية (بحد أقصى عددين). لا يظهر الأرشيف الثانوي إذا لم توجد أعداد سابقة.
- عنوان البطاقة مشتق من `title_ar` المنشور بعد حذف بادئة «الإحاطة اليومية» فقط، دون صناعة عنوان سياسي جديد. نصوص المقتطفات من `executive_summary` دون إعادة صياغة.
- لا Migration ولا تغيير لقواعد Supabase ولا صلاحيات ولا بيانات نشر.
- لا مكتبات أيقونات إضافية؛ SVG مضمّن بخطوط رقيقة مع `aria-hidden`.

## ملاحظات المنتج

- لا يوجد حقل مستقل لعنوان واجهة العدد؛ يستخدم الإصدار الحالي `title_ar`. إضافة حقل جديد إلى غرفة التحرير/البيانات مسألة لاحقة منفصلة.
- لا تُعرض أرقام التطورات والخلاصات إلا إذا نجحت قراءة تفاصيل العدد، لتجنب إيهام المستخدم بأرقام غير متاحة.
- لم يجرِ تغيير قسم `/briefings` أو صفحات الإحاطة الداخلية أو مسار الطباعة.
- تاريخ الأعداد والأرقام يستخدم التنسيق العربي مع أرقام لاتينية.
