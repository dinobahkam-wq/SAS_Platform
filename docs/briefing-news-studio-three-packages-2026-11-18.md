**المشروع:** `dinobahkam-wq/SAS_Platform`  
**قاعدة العمل:** GitHub هو مصدر الحقيقة؛ تُنفّذ كل حزمة بفرع وطلب دمج واختبارات قبول. لا يبدأ تنفيذ الحزمة التالية إلا بموافقة المستخدم الصريحة. لا حذف للبيانات المنشورة أو العبث بلقطات المراجعات السابقة.

## المبادئ التحريرية والتقنية
- **الإحاطة اليومية** منتج للسجل الموثق للتطورات، والمؤشرات القياسية والتغيرات؛ ليست منصة مقالات تفسيرية مستقلة. تظل «قراءة ساس» ضمن قسم «التحليل والدراسات» عند الحاجة.
- تحفظ السجلات التاريخية والحقول القائمة وقابلية التدقيق؛ يجب التفريق بين إخفاء قسم تفسيري من الواجهة وبين حذف بيانات محفوظة.
- **المنتج البصري** مشتق من رقم إصدار محدد وتطور محدد؛ يجب حفظ هوية المصدر، حالة التحقق وتاريخ الواقعة. لا تُحوَّل ادعاءات الأطراف إلى حقائق في PNG.
- الاستوديو أداة للمحررين المخولين فقط؛ لا ينبغي إتاحة أدوات الإنشاء أو رفع الصور للجمهور.
- خطوط ساس: **Thmanyah Sans** للنصوص والأرقام ومؤشرات البيانات، **Tajarib Taweel** للعناوين التحريرية. استثناء خط رموز `Material Symbols` للأيقونات فقط.
- المعايير المطلوبة: تصميم عربي RTL؛ أرقام لاتينية؛ قابلية الاستخدام للهاتف والطباعة والنسق الداكن؛ لا تخزين مؤقت يخلط إصدارات الأعداد؛ عدم تسريب رموز الوصول.

## مخرجات الحزمة 2 — تنفيذ البرمجة دون دمج

- إجراء «إنشاء بطاقة بصرية» بجانب التطور، يظهر فقط لحسابات `user_roles.role=admin` النشطة عند جلب الإحاطة.
- المسار `/admin/news-studio/briefing/[slug]/[order]?revision=N`، مع حراسة مستقلة بواسطة `requireAdmin`، وجلب أحدث لقطة منشورة من `getPublicBriefing` والتحقق من رقم المراجعة الأصلي؛ عند اختلاف المراجعة يظهر تنبيه برفض النقل القديم.
- معلومات URL مقتصرة على الهوية ورقم المراجعة والترتيب الأصلي؛ **لا نصوص أو روابط مصادر تمر عبر URL أو localStorage**.
- `src/lib/briefing-studio-transfer.ts` يحوّل بيانات التطور إلى الحقول التي يدعمها الاستوديو: العنوان، الملخص، المصدر الأساسي، تاريخ الحدث (بتوقيت اليمن) أو تاريخ العدد إن غاب، المحافظة، التصنيف، ومراجع المصادر وحالة التحقق.
- `src/components/briefing-studio-handoff-context.tsx` يمرر الحمولة إلى محرك الاستوديو في React دون تخصيص `PageProps` الخاصة بـ Next.js.
- News Studio يعيد استخدام محرر الخبر الحالي وقائمة القوالب والصور؛ يعرض لوحة أصل المادة، والتنبيه للادعاءات غير المثبتة، وتفاصيل المصادر في مساحة الإدارة. يترك للمدير مراجعة البيانات قبل التصدير، ولا يغير سجل الإحاطة.
- لم تُضف أي API عامة أو Migration أو سياسة RLS جديدة. **الأدوار الأخرى غير `admin` لا يسمح لها التخويل الحالي بالدخول إلى غرفة التحرير**؛ توسيعها يحتاج قرار صلاحيات مستقل.
- تمت مراجعة اتساق المصدر برمجيًا، وأضيف `scripts/check-briefing-to-studio-package2.mjs`. اختبار Node وTypeScript والبناء والتحقق التفاعلي مؤجلة إلى مرحلة الاختبار النهائي بعد الحزمة 3.

## الحزمة الثانية — نقطة التكامل الآمن من التطور إلى News Studio (معلقة على الموافقة)
**النطاق المتوقع:** فحص آليات الاستوديو الحالية وصلاحيات الإدارة، وإضافة إجراء «إنشاء بطاقة بصرية» داخل واجهة المحرر أو كإجراء لا يظهر إلا للمستخدم المخول؛ نقله إلى News Studio بهوية التطور/المراجعة (مع التحقق من صلاحياته)، وجلب البيانات من الخادم بدل تمرير نصوص قابلة للتلاعب عبر URL. تعبئة العنوان، الملخص، الفئة، الموقع، التاريخ، نسبة الادعاء، المصدر المرجعي، رقم العدد ومكان التطور؛ مع إمكانية التحرير دون تعديل الحدث المصدر.
**الاختبارات:** زائر غير مسجل لا يرى الإجراء ولا يستطيع استخدام API؛ مستخدم مخول يصل إلى الاستوديو والبيانات الصحيحة؛ رفض المعرفات غير الموجودة أو المحذوفة أو التي لا تملك إذنًا؛ ألا يغير فتح الاستوديو بيانات الإحاطة؛ اختبار مسارات الخطأ والنقص.
**المخرج:** PR مستقل يُختبر ويعتمد قبل المرحلة الثالثة.

## الحزمة الثالثة — القالب البصري والتصدير PNG (معلقة على الموافقة)
**النطاق المتوقع:** نموذج نصي رسمي يحوي شعار ساس الملوّن والعنوان والبيانات التحريرية المرجعية، مع خيار إضافة صورة الحدث بصورة اختيارية من رفع المستخدم أو مخزن الوسائط المسموح. خيارات القص/التحريك وحدود الهوامش، ومقاس 1080×1080 (1:1) كبداية، ثم 1080×1350 (4:5) بعد ضبط النموذج. تصدير PNG بدقة فعلية مع عدم سقوط الخطوط المحلية، وبقاء روابط التوثيق والأوصاف في الملف التحريري وليس حشوًا داخل الصورة.
**الاختبارات:** أنواع الصور المسموحة والحجم، حماية تنزيل الصور البعيدة، النص العربي الطويل، خطوط ساس في PNG، وضوح الشعار، متغيرات النسق، تشغيل بلا صورة، وتناسق المعاينة والملف النهائي. مراجعة مثالين حقيقيين بتاريخين مختلفين.
**المخرج:** قالب واحد معتمد وآلية تصدير موثوقة، ثم توسعات لاحقة بموافقة منفصلة.
